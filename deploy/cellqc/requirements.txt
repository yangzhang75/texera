# The Python side of the cellqc workflow, installed into the interpreter the
# PythonUDF workers run (udf.conf `python.path` / $UDF_PYTHON_PATH) -- not the
# system python. Installing anywhere else changes nothing the workflow can see,
# and the failure reads as a code bug: `ModuleNotFoundError: No module named
# 'cellqc'` from inside an operator.
#
# Four lines, because four is what the workflow actually imports that nothing
# else brings in. scanpy declares h5py, numba, scikit-learn, matplotlib, numpy,
# pandas, scipy and anndata itself, so pinning those again here would be a
# second opinion that can only ever conflict with scanpy's own.

scanpy==1.12.1         # and with it anndata, numpy, pandas, scipy, h5py, numba,
                       #   scikit-learn, matplotlib -- the stack cellqc's Python
                       #   stages run on
pysam==0.24.0          # nuclear_fraction reads the Cell Ranger BAM with this
jinja2==3.1.6          # qcreport.py renders report.html from bundled templates
requests==2.34.2       # Publish Result talks to the file service over REST

# cellqc declares click and PyYAML too; neither is needed here. click is only
# imported by its CLI, which the workflow does not use -- the operators are the
# scheduler -- and PyYAML only by slidereport.py, which builds the PDF slide deck
# the workflow does not build. Installing cellqc --no-deps is what keeps them out.
#
# The versions the reference run was validated against, for a build that has to
# be reproduced exactly: anndata 0.12.18, numpy 2.1.0, scipy 1.18.0, pandas
# 2.2.3, h5py 3.16.0, numba 0.65.1, matplotlib 3.11.0, scikit-learn 1.9.0,
# under Python 3.12.13.

# --- cellqc itself, and the runner that drives it ---
#
# NOT from PyPI. PyPI's newest is 0.3.2; 0.3.3 is what introduced the
# configurable `geneset` section, and without it a reference that names its
# mitochondrial genes bare (Ensembl Mmul_10) silently reports pct_counts_mt == 0
# for every cell -- a QC run that looks fine and filters nothing.
#
# --no-deps on purpose: cellqc declares snakemake, whose CLI the workflow does
# not use, and pulling it in churns the UDF interpreter's environment for nothing.
#
#   pip install --no-deps git+https://github.com/lijinbio/cellqc.git@v0.3.3
#   pip install --no-deps deploy/cellqc          # the cellqc_texera runner
