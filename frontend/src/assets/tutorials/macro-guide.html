Run an analysis with a Macro

A Macro is a ready-made analysis someone already built for you. Open it, adjust a few settings, and press Run — no coding. This guide covers what Texera is, how to run a Macro, and how to read the results.

1 The idea

In Texera, an analysis is a workflow: a chain of building blocks (operators) wired left to right — read data → process → show results. You run it in your browser.

A Macro is a finished workflow that an expert packaged, leaving a few settings open for you to fill in. You don't touch the internal steps — you adjust the blanks and run.

The Macros you'll use are marked Runnable: they already contain their data and run on their own. Ones shared for everyone also show Public.

You may also see Not runnable. Those are half-built — someone still needs to wire in a data source. They're meant for people building Macros, so this guide sticks to Runnable ones.

2 Where to find Macros

Both live in the left sidebar:

  • Hub → Macros — the public gallery (browse everyone's, even logged out).
  • Your Work → Macros — your own, and ones shared with you.

Flip the All / Runnable filter to Runnable, then click a row to open it.

3 Two ways to open one: Clone vs Generate

When you click a Macro that isn't yours, you get a read-only preview with two buttons. They do different things:

▶ Generate workflow

Opens the fill-in-settings page so you can run it. It produces a workflow (the thing that runs) — it does not add a Macro to your list. Use this when you just want results.

⧉ Clone

Saves your own copy of the Macro into Your Work → Macros, so you can reuse it later (and tweak or share it). Clone first if you'll come back to it.

In short: Generate = run now; Clone = keep for later. (Your own Runnable Macros open Generate directly when clicked.)

4 Run a Macro, step by step

  1. Open it and adjust the settings

    Click a Runnable Macro, then Generate workflow. On the Generate workflow from macro page, give it a Macro name and fill in the settings. They're grouped by the block they belong to; nested Macros' settings appear here too, tagged by name. Fields with a red ✱ are required.

    Example: the input File — press Select File to point it at your dataset — and n_hvg, the number of highly-variable genes to keep (e.g. 1500).

    Just want to see it work? Runnable macros come with working defaults — you can skip changing anything and go straight to Run. For example, the public VisionKB: Human Retina Cell Type Annotation (scGPT) macro runs end to end on its default data, so you can Generate → Run it as-is to try Texera.

  2. Set up a computing unit

    A computing unit is the machine that runs your analysis. In the top bar, open the computing-unit dropdown. If one already shows a green dot ●, just select it — otherwise click + Computing Unit.

    In the dialog, set Type Kubernetes, a Name, RAM (e.g. 8Gi) and CPU cores (e.g. 8), then Create. The unit needs a short while to start — its dot turns green and the Run button turns blue only once it's ready. Select it and wait for that.

  3. Press Run

    Once the Run button has turned blue (the computing unit is ready), press it. Texera runs the analysis and automatically saves it as a workflow under Your Work → Workflows — nothing to create by hand.

    The operators turn green as they finish. The run is done when the last node turns green ●.

    Big datasets take a while. A large single-cell file can take many minutes — the run is working even if nothing seems to change. Let it finish.

  4. Read the results

    Results show in the Result panel — a box at the bottom-left of the preview. If it didn't open on its own, click it open. Inside you'll find the output tables and charts, which you can export.

Just want to save it without running? Use Create Workflow instead of Run — it stores the workflow so you can open and run it later.

5 If something goes wrong

"Failed to get presigned URL: 401" while running. Your login session expired — log out and back in (restart the computing unit if it had been open a long time), then Run again.
Run is greyed out / there's no computing unit. Create one first (Step 2) and wait for its green dot before running.
There's no Run, or it won't finish. The Macro may be Not runnable — pick one marked Runnable instead.
A setting asks for a data file I can't open. You can only use datasets you own or that were shared with you — ask the owner to share it.

Glossary

Workflow
a chain of operators that performs an analysis.
Operator (node)
one building block; turns green when it finishes.
Macro
a packaged workflow with a few settings left open.
Runnable
a Macro that includes its own data and runs on its own.
Computing unit
the machine that runs your workflow; create/select it before Run.
Result panel
the box (bottom-right of the preview) that shows output tables and charts.
